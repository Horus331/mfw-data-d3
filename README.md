# mfw-data-d3

Data for the whole-District-3 storm replays of [Mass Flood Watch](https://horus331.github.io/mass-flood-watch/) (LISFLOOD-FP 8.2 at 20 m on WPI's Turing GPU cluster, NOAA MRMS radar rain). Served by GitHub Pages at https://horus331.github.io/mfw-data-d3/ and read by the viewer; not meant to be browsed directly.

Each storm is one folder: `<storm>/meta.json` plus water-depth tiles. Code and methods: https://github.com/Horus331/mass-flood-watch
